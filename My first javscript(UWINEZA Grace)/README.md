# Starlight shop
## Project Description
This project is a simple javscript program that calculates a customer's order and displays a receipt in the browser console.
## Business Scenario
Starlight shop sells stationery products. The program calculate the cost of notebooks purchesed by a customer and add a delivery fee.
## Order Information
-Business Name: Starlight shop
-Customer Name: UWINEZA
-Product: Notebook
-Unit Price: 1500
-Quantity: 4
-Delivery fee: 1000 RWF
## Calculations
Subtotal = Unit price * Quantity
subtotal = 1500 * 4 = 6000 RWF
Total Cost = Subtotal + Delivery Fee
Total Cost = 6000 + 1000 = 7000 RWF
## Project Files
index.html: Connect the HTML page to the JavScript file.
script.js: calculates the order and displays the receipt.
README.md: Explain the project.
## How to Run the Program
Open index.html in the a web browser.
Open the browser Developer Tools
Select the console tab.
view the customer receipt.
